# Task: AlphaFold 3 Protein-Ligand Structure Prediction

## Objective
Implement and evaluate AlphaFold 3's diffusion-based architecture for protein-ligand structure prediction across diverse biomolecular complexes.

## Requirements
1. Evaluate blind protein-ligand docking success rate (RMSD < 2.0 Å) against baselines
2. Visualize predicted protein-ligand complexes showing key interactions
3. Demonstrate cross-complex generalization (protein-nucleic acid, antibody-antigen)
4. Show training convergence curves comparing with previous architecture
5. Conduct ablation studies to validate architectural components

## Evaluation
- Success rate metric (RMSD < 2.0 Å)
- Interaction accuracy (H-bonds, hydrophobic, π-stacking)
- Cross-complex performance
- Training convergence speed
- Component importance via ablation
